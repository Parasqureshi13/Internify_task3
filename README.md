# Creative Web Solutions

A professional multi-page website built using **HTML, CSS, and JavaScript** as part of **Internify Task 3**.

The project focuses on creating a consistent, responsive, and user-friendly experience across multiple pages.

## 📌 Project Overview

Creative Web Solutions is a 3-page website containing:

* Home Page
* About Page
* Contact Page

The website includes responsive layouts, JavaScript-powered mobile navigation, dark/light mode, and client-side form validation.

## 🚀 Features

* Responsive design for mobile, tablet, and desktop
* Consistent navigation across all pages
* JavaScript mobile hamburger menu
* Smooth mobile navigation animation
* Dark mode / Light mode toggle
* Theme preference saved using Local Storage
* Contact form validation
* Required field validation
* Minimum character validation
* Email format validation
* Error messages under form fields
* Success message after valid submission
* Font Awesome icons
* Modern and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts
* Local Storage

## 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* Mobile phones
* Tablets
* Laptops
* Desktop computers

The navigation automatically changes to a mobile hamburger menu on smaller screens.

## 🌙 Dark / Light Mode

Users can switch between light and dark themes using the theme toggle button.

The selected theme is stored in **Local Storage**, so the preference remains available when navigating between the website's pages.

## 📩 Contact Form

The Contact page includes JavaScript-based validation for:

* Name
* Email
* Message

The form displays appropriate error messages when the entered information is invalid and shows a success message when all fields are correctly completed.

No backend is required for this project.
